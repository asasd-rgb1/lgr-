# 4 秒技术样片 · 圆的影子，是一条波

目标：一个点匀速绕圆转动，它的竖直坐标被同步记录，逐渐画出一周期正弦曲线。只验证工程和视觉方向，不扩展为完整知识短片。

## 脚本与连续分镜
| 时间 | 连续动作 | 画面文字 |
| --- | --- | --- |
| 0–0.3 s | 圆、坐标轴与圆周点已经可见；短连接线建立空间关系 | 圆的影子，是一条波 |
| 0.3–1.15 s | 圆周点匀速向上运动；右侧记录点同步走向波峰 | 匀速转动，记录竖直位置 |
| 1.15–2.85 s | 点经过上、下半圆；同色水平连线保持相同高度，轨迹连续累积 | y = A sin(ωt) |
| 2.85–3.7 s | 点回到起点，曲线完成一个周期；不存在场景翻页 | 保留完整公式和图形 |
| 3.7–4 s | 完整图形短暂停留，结尾保留有效画面 | 无新增文字 |

视觉：深蓝黑背景、暖白标题、青绿色轨迹、琥珀色半径；大留白、细网格。圆与曲线始终处于同一场景。无配音、音乐或付费生成服务。

技术：1920×1080 / 30fps / 120 帧；首次 MP4 用 0.5 倍缩放，即 960×540。另注册同样 4 秒的 60fps 版本以验证按秒换算，不执行完整高清渲染。

## 事实与范围
- 圆半径 A、角速度 ω 恒定，初始相位为 0，数学坐标 y 向上。
- t 是从开始转动起计算的时间；转动持续 3.4 秒，ω = 2π / 3.4。
- SVG 屏幕 y 轴向下，因此绘图使用 `centerY - A * sin(ωt)`。
- 右图为位置随时间的记录，不表示介质中的波传播；“波”仅指正弦曲线形状。
- 来源和允许措辞见 `../research/claims.md`。
